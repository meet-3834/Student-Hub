🌐 Practical 6: Fetch API Dynamic Rendering, Search & Filter

Practical 6

Asynchronous data consumption with search, category filtering, multi-field sorting, pagination, and localStorage caching.

  • events.html (Events Directory) — Dynamic cards from events.json with live search, category filter, date/capacity sorting, and pagination.
  • students.html (Student Directory) — Dynamic profiles with Dependent Location Dropdowns (Country → State → City) (Intermediate Extension) and CGPA sorting.

🐘 Practical 7: PHP Form Processing & File Storage (CSV/JSON)

Practical 7

Server-side validation, data sanitization, safe CSV/JSON storage, and CSRF token verification.

  • contact.php — Contact inquiry form protected by CSRF Token (Advanced Extension), plus live table displaying stored records (Intermediate Extension).
  • process.php — POST processor that validates server-side inputs with regex and filter_var, verifies CSRF token, and safely appends records to CSV and JSON.
  • data/records.csv & data/records.json — Persistent file-based storage targets.
  • contact.html — Static contact information and location directions.

🗄️ Practical 8: MySQL Schema Design, ER Model, PDO & Stored Procedures

Practical 8

Normalized relational database schema (Students, Events, Registrations), secure PDO connection, and stored procedures.

  • test_db.php — Live verification test dashboard demonstrating PDO connection, prepared statements, and stored procedure execution (Screenshot-ready for lab submission).
  • schema.sql — Complete SQL dump file containing table definitions (3NF normalized), foreign keys, seed data, and stored procedures for phpMyAdmin.
  • db.php — Secure PHP PDO singleton connection with exception handling and native prepared statements.
  • setup.php — Automated database initialization script for CLI and XAMPP.
  • students_api.php — Secure database-backed REST API for student records.

🛡️ Practical 9: Secure Registration, Duplicate Email Check & Password Hashing

Practical 9

Secure user registration inserting records into MySQL using PDO prepared statements, checking duplicate email, password hashing, and audit logging.

  • register.php — Secure backend registration form with duplicate email verification (SELECT id FROM users WHERE email = ?), password_hash(), and quick-fill test case helpers for valid, duplicate, and invalid test reporting.
  • auth.php (logAudit()) — Advanced Extension: Cryptographic CSRF token validation and automated audit logging to audit_logs database table & data/registration_audit.log.

🔐 Practical 10: Secure Login/Logout, RBAC, Session Timeout & Remember-Me

Practical 10

Secure authentication with password_verify(), session fixation prevention via session_regenerate_id(), role-based dashboards, 15-minute inactivity timeout, and random selector/validator remember-me tokens.

  • login.php — Secure authentication form with quick-fill test accounts, timeout notice, logout notice, and 30-day Remember-Me checkbox.
  • student-dashboard.php — Student portal dashboard displaying last-login timestamp, active session ID, simulated timeout button, and unauthorized access test button.
  • admin-dashboard.php — Administrator control center displaying last-login timestamp and live registration/auth audit log entries.
  • logout.php — Secure POST logout handler with CSRF token verification that clears remember cookies and destroys sessions.
  • auth.php (requireRole()) — Blocks unauthorized dashboard access and renders a screenshot-ready 403 Forbidden screen.
